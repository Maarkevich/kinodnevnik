# Кинодневник

**Личный дневник фильмов и сериалов.** Русскоязычное PWA: работает офлайн, устанавливается на телефон и десктоп, не требует аккаунта и не имеет сервера — все данные живут только на вашем устройстве.

Форк проекта [Open Movie Tracker](https://github.com/r-shafi/open-movie-tracker) (MIT © 2024 R. Shafi) с переработанной архитектурой хранения, интерфейсом и навигацией.

> **Статус:** идёт реализация по [спецификации](docs/SPEC.txt). Репозиторий создан, код в процессе.

---

## Для кого это

Для тех, кто смотрит много и по-разному: фильмы, сериалы, мультсериалы, аниме, дорамы. Приложение не пытается быть соцсетью и не рекомендует «что посмотреть всем». Оно ведёт ваш личный учёт: что посмотрели, когда, как оценили, что отложили, и что из этого следует про ваш вкус.

## Что умеет

- **Запись просмотра в одно касание** — оценка от 0,5 до 5,0 шагом 0,5 (полузвёзды), дата, заметка, метки. Пересмотры считаются отдельно, а не перезатирают первую запись.
- **Статусы**: «Смотрю», «Пересматриваю», «Брошено» — недомотренное отличается от просмотренного, а очередь отложенного имеет смысл.
- **Сериалы и аниме** — отметок серий поштучно, прогресс по сезону.
- **Дневник** — лента записей, сгруппированная по месяцам, с фильтрами по типу и сортировками.
- **Подборки** — категории поверх TMDb: мультфильмы, аниме, корейские/китайские/тайские дорамы, турецкие и испанские сериалы, «похожие на просмотренное», случайное из отложенного.
- **Поиск** — по названию, меткам и собственному тексту; понимает транслит с русской раскладки (`fkmrf` → «фильм») и не различает ё/е.
- **Свои списки** и избранное.
- **Аналитика** — распределение оценок, темп просмотров, тепловая карта 365 дней с сериями подряд, расхождение ваших оценок с TMDb, «индекс нишевости», возраст фильма на момент просмотра, жанры, страны производства, топ режиссёров и актёров.
- **Где смотреть** — провайдеры для региона RU (Okko, Кинопоиск, Amediateka, More TV, Premier и др.), если TMDb отдаёт по ним данные.
- **Резервные копии** — экспорт/импорт сжатым файлом. Импорт работает как синхронизация: добавляется только то, чего нет, без дублей, а удалённое не возвращается.

## Приватность

- Аккаунта нет. Сервера нет. Телеметрии нет.
- Данные хранятся в IndexedDB вашего браузера. Никуда не отправляются.
- Единственная внешняя связь — запросы к The Movie Database за метаданными и картинками.
- Ваш TMDb-ключ хранится только на устройстве и не попадает ни в репозиторий, ни в резервные копии.
- Электронная почта, адрес, имя и сайт из импортируемых файлов **не читаются и не сохраняются**.

> Установка на iOS: добавьте на домашний экран — так хранилище защищено от очистки системой. Приложение регулярно напоминает сделать резервную копию, потому что браузер в принципе может её удалить.

## Первый запуск

1. Откройте приложение.
2. Введите ключ API TMDb (поле при старте; получить — на [themoviedb.org/settings/api](https://www.themoviedb.org/settings/api), тип **API Key (v3 auth)**).
3. Отметьте первый фильм кнопкой **⊕** в центре нижней панели.

Ключ нужен, чтобы приложение находило фильмы. Он виден в сетевых запросах браузера — это нормально для клиентского приложения без сервера, но означает, что делиться им не стоит.

## Технологии

Angular 21 · Ionic 8 · TypeScript 5.9 · Tailwind 3 · IndexedDB · Service Worker (собственный, без `@angular/pwa`) · PWA.

Офлайн — основное состояние, а не запасной режим: дневник, списки, оценки и аналитика работают без сети, картинки берутся из кэша.

Обновления: все сборки содержат хэши в именах файлов, а service worker проверяет новую версию при запуске, при возврате в приложение и каждые 30 минут. Когда обновление найдено, вы видите кнопку «Обновить» — молча перезагружать посреди ввода данных приложение не будет.

## Дизайн

Тёмная тема, акцент `#49effb`, шрифт [Nunito](https://fonts.google.com/specimen/Nunito) (полная кириллица, раздаётся вместе с приложением), скруглённые углы и «стеклянные» оверлеи с `backdrop-filter` — с обязательным затемнением под светлыми постерами и уважением к системным настройкам «уменьшить прозрачность» и «уменьшить движение».

## Разработка

```bash
npm install
npm start          # ng serve, http://localhost:8100
npm test           # unit-тесты
npm run e2e        # Playwright
npm run build      # продакшен-сборка с хэшами в именах
```

Коммиты — [Conventional Commits](https://www.conventionalcommits.org/), проверяется хуком. Ветвление: `main` защищён, всё через PR.

Полное описание того, как устроен продукт и что именно реализовано, — в файле **[docs/SPEC.txt](docs/SPEC.txt)**. Он же является контрактом: если поведение расходится со спецификацией, это баг.
